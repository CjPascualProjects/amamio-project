HOW TO RUN — Amamio Farm Products Sales & Inventory Management System
=====================================================================

REQUIREMENTS
  - Python 3.9+ (tested on 3.11+)
  - pip

SETUP (one time)
  1. Open a terminal in this folder.
  2. (optional) create a virtual environment:
        python -m venv venv
        # Windows:        venv\Scripts\activate
        # macOS / Linux:  source venv/bin/activate
  3. Install dependencies:
        pip install -r requirements.txt

     This step matters: without the "qrcode" package the system still runs,
     but QR labels print as a plain box showing the code text instead of a
     real scannable QR code.

RUN
        python run.py

  Then open http://localhost:5000 in your browser.

VERIFY (optional)
        python smoke_test.py
  Runs an end-to-end self-test (logins, role guards, receiving with damage,
  honey QC, packing, QR receive, orders, MySQL export) against a throwaway
  temp folder — it never touches your data.

THE QR CODES
  Four kinds of code circulate, told apart by their prefix. All four are
  scanned on the same screen (QR Scanner):

        RB-<n>   a receiving cage box / crate
        HC-<n>   a honey container
        PK-<n>   a packing run
        PR-<a>-<b>  an approved purchase-request item

  Labels print from: Receiving Area > a batch > Print QR labels, and
  Honey QC > Print QR labels.

SALES PLATFORM FILES
  Put the marketplace exports (.xlsx) in the "sales-platform" folder next to
  this one, then go to Sales Platforms > Import a file. Shopee, Lazada and
  TikTok templates ship ready to use; add a template for any other
  marketplace under Sales Platforms > Templates (it is a column mapping, not
  a code change).

MOVING TO MySQL
  Sign in as the Super Admin and open MySQL Export, or run:

        python mysql_export.py

  which writes export/schema.sql and export/data.sql. Then on the server:

        mysql -u root -p -e "CREATE DATABASE amamio_ims CHARACTER SET utf8mb4"
        mysql -u root -p amamio_ims < schema.sql
        mysql -u root -p amamio_ims < data.sql

NOTES
  - Demo data is created automatically on first run (in the data/ folder).
  - To reset everything, stop the app and delete the data/ folder, then run
    again.
  - Everything runs offline — no database server and no internet needed.
  - In production set a real secret key before starting:
        Windows:        set AMAMIO_SECRET_KEY=some-long-random-string
        macOS / Linux:  export AMAMIO_SECRET_KEY=some-long-random-string
