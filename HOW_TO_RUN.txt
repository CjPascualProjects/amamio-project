HOW TO RUN — Amamio Farm Products Inventory & Sales System
==========================================================

REQUIREMENTS
  - Python 3.9+ (tested on 3.14)
  - pip

SETUP (one time)
  1. Open a terminal in this folder.
  2. (optional) create a virtual environment:
        python -m venv venv
        # Windows:        venv\Scripts\activate
        # macOS / Linux:  source venv/bin/activate
  3. Install dependencies:
        pip install -r requirements.txt

     This step matters: without the "qrcode" package the system still runs,
     but QR labels print as a plain box showing the code text instead of a
     real scannable QR code.

RUN
        python run.py

  Then open http://localhost:5000 in your browser.

  To use it from phones / tablets on the same Wi-Fi (e.g. scanning QR codes
  on the floor), start it like this instead — it prints the address to open:
        Windows:        set AMAMIO_HOST=0.0.0.0 && python run.py
        macOS / Linux:  AMAMIO_HOST=0.0.0.0 python run.py
  (Debug mode is switched off automatically when it is reachable from the
  network. For a permanent install use a real server, e.g. gunicorn app:app.)

VERIFY (optional)
        python smoke_test.py
  End-to-end self-test against a throwaway temp folder — it never touches
  your data.

DEMO LOGINS (username / password)
        superadmin / super123     Super Admin
        admin      / admin123     Admin
        receiving  / recv123      Receiving Team Head
        production / prod123      Production Team Head
        packing    / pack123      Packing Team Head

  Change these before the system is used for real: Users > Reset password.

EVERYDAY USE
  After signing in, Home shows the few things your role does. Every
  transaction is a short step-by-step flow (Back / Next, then a check screen
  before saving). Scan a QR code from the menu to open any box, honey
  container or packing run.

QR CODES
        RB-<n>      a receiving box / crate
        HC-<n>      a honey container
        PK-<n>      a packing run
        PR-<a>-<b>  an approved purchase-request item
  Labels print right after a delivery or honey containers are recorded.
  The QR carries the code plus the item, quantity and delivery details.

SALES FILES (Module 5)
  Sales Uploads & Reports > Upload sales file. Shopee, TikTok Shop, Lazada
  (Excel) and Shopify (CSV) are built in. Uploaded files are kept in the
  "sales-platform" folder of this project (set AMAMIO_SALES_DIR to use
  another folder). Re-uploading a newer export updates statuses instead of
  counting orders twice.

HONEY PRODUCT LISTS
  The products PASSED and FAILED honey go into are placeholders. Edit
  HONEY_PASS_PRODUCTS and HONEY_FAIL_PRODUCTS in services.py.

MOVING TO MySQL
  Sign in as the Super Admin and open MySQL Export, or run:

        python mysql_export.py

  which writes export/schema.sql and export/data.sql. Then on the server:

        mysql -u root -p -e "CREATE DATABASE amamio_ims CHARACTER SET utf8mb4"
        mysql -u root -p amamio_ims < export/schema.sql
        mysql -u root -p amamio_ims < export/data.sql

NOTES
  - Demo data is created automatically on first run (in the data/ folder)
    from the client's own forms: product list, supplies, asset register and
    supplier directory. Prices and stock levels are demo figures.
  - To reset everything, stop the app and delete the data/ folder, then run
    again.
  - Everything runs offline — no database server and no internet needed.
  - In production set a real secret key before starting:
        Windows:        set AMAMIO_SECRET_KEY=some-long-random-string
        macOS / Linux:  export AMAMIO_SECRET_KEY=some-long-random-string
