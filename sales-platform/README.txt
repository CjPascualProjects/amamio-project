SALES-PLATFORM FOLDER
=====================

Exports from Shopee, TikTok Shop, Lazada, Shopify and other platforms are
kept here (Excel .xlsx or CSV). Files uploaded through
Sales Uploads & Reports > Upload sales file are saved here too.

These files contain real customer names, addresses and phone numbers, so
they are NOT stored in the git repository (see .gitignore). Keep them on
the computer that runs the system, or set AMAMIO_SALES_DIR to a private
shared folder.

On a fresh install with no data/ folder, any exports placed here are
imported automatically the first time the system starts.
