MySQL export

The JSON store is already shaped as a relational database. Download the schema and the data, and the system moves onto MySQL without a rewrite.

Download schema.sql Download data.sql
How to migrate
  1. Download schema.sql and data.sql above.
  2. On the server, create the database:
    mysql -u root -p -e "CREATE DATABASE {{ database }} CHARACTER SET utf8mb4"
  3. Load the structure: mysql -u root -p {{ database }} < schema.sql
  4. Load the data: mysql -u root -p {{ database }} < data.sql

The same two files can be produced from the command line with python mysql_export.py, which writes them into export/.
